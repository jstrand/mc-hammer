Server Details

Inspect and delete a running server.



                        

                          
Managing players

                          

                            Commands run against the live server, so it must be running.
                            Player names are looked up with Mojang and must be spelled exactly —
                            there is no search or partial matching.
                          


                          
Whitelist — who may join

                          
New servers are created with the whitelist on, and it starts empty,
                             so nobody can connect until you add them.

                          

                            
whitelist add <player>

                            
Let a player join. Takes effect immediately.

                            
whitelist remove <player>

                            
Revoke access. Kicks them if they are online.

                            
whitelist list

                            
Show everyone currently whitelisted.

                            
whitelist on / whitelist off

                            
Turn enforcement on or off without clearing the list.

                            
whitelist reload

                            
Re-read whitelist.json after editing it by hand.

                          


                          
Operators — who may use admin commands

                          
Ops can run admin commands in-game and bypass spawn protection.
                             Being an op is separate from the whitelist: an op who is not
                             whitelisted still cannot join.

                          

                            
op <player>

                            
Grant operator status. Recorded in ops.json.

                            
deop <player>

                            
Revoke operator status.

                          


                          

                            To let a new admin in, you need both:
                            whitelist add Alex then op Alex.
